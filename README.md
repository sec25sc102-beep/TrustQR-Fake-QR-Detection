# TrustQR – Smart Fake QR Code Detection System

## Problem Statement
Fake QR codes can redirect users to fraudulent payment accounts or malicious websites.

## Proposed Solution
TrustQR is a cybersecurity project that scans QR codes, extracts their contents, checks URLs for suspicious indicators, and warns users before they proceed.

## Features
- QR code scanning
- URL safety checks
- Suspicious link warnings
- Digital payment safety tips

## Technologies
Python, HTML, CSS and JavaScript.

## Project Status
Prototype under development.
