# TrustQR Test Cases

## Test Case 1: Safe URL
Input: https://www.google.com  
Expected Result: Display the URL for review.

## Test Case 2: Suspicious URL
Input: http://example-suspicious-site.test  
Expected Result: Flag the URL for caution.

## Test Case 3: Invalid Input
Input: Empty input  
Expected Result: Display an error message.

## Safety Note
The prototype provides basic URL checks and cannot guarantee that a website or QR code is safe.
